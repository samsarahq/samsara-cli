# Security Policy

## Reporting a vulnerability

Email **security@samsara.com**. Please include reproduction steps and the CLI
version (`samsara version`).

Do not open a public GitHub issue for security reports.

## Scope

The `samsara` CLI binaries distributed through this repository's GitHub
Releases, and the channels that point at them (Homebrew tap, winget, the
install scripts on cli.samsara.com).

## Response

Samsara Security acknowledges reports and coordinates a fix with the reporter
before any public disclosure.
